# AI Resume Analyzer

An intermediate-level AI/NLP project that analyzes resumes and compares them with job descriptions.

## Team Modules
1. NLP & Resume Parser
2. AI/ML Matching Model
3. Flask Backend Integration
4. React Frontend & QA

## Planned Stack
- Python
- Flask
- scikit-learn
- NLP
- React
- HTML/CSS/JavaScript

## Quick Start

### Backend
```bash
cd backend
python -m venv venv
# Windows:
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

This starter project is a scaffold. Extend the parser, matching model, frontend, testing, and documentation as your team develops the project.
